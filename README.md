Simple CRUD API

Dev server:
1. run `npm run start:dev`
2. test commands using curl or Postman (Postman is preferred) (GET/POST/PUT/DELETE)

Prod server:
1. run `npm run start:prod`
2. same as dev server

JEST Tests:
1. stop all servers
2. run `npm run test`

Claster mode:
1. run `npm run start:multi`
2. same as dev server
3. you can test using bash script `bash ./scripts/highload.sh`
